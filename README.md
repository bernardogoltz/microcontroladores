# Microcontroladores 

Trabalhos da disciplina de Microcontroladores, assembler
ATmega328P e simulados no SimulIDE.

| Trabalho | Título |
|---|---|
| [Trabalho 2](trabalho-2/) | Calculadora com teclado matricial e displays de 7 segmentos |
| [Trabalho 3](trabalho-3/) | Termômetro de 3 canais com ADC e displays multiplexados |
| [Trabalho 4](trabalho-4/) | Média de 4 sensores de temperatura em displays de 7 segmentos |
| [Trabalho 5](trabalho-5/) | Brilho de um LED por PWM: valor digital de 8 bits e potenciômetro |
| [Trabalho 6](trabalho-6/) | PWM de 10 kHz no Timer1 com duty cycle pelo potenciômetro |

Cada pasta tem o código em assembly (`src/`), o circuito do SimulIDE
(`simulide/`) e, quando houver, o GIF da simulação (`docs/`), mostrados no
`README.md`.
