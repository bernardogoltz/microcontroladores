# Microcontroladores 

Trabalhos da disciplina de Microcontroladores, para o ATmega328P,
simulados no SimulIDE. Os trabalhos 2 a 6 são em assembly e os 7 a 9, em C++ no Arduino.

| Trabalho | Título |
|---|---|
| [Trabalho 2](trabalho-2/) | Calculadora com teclado matricial e displays de 7 segmentos |
| [Trabalho 3](trabalho-3/) | Termômetro de 3 canais com ADC e displays multiplexados |
| [Trabalho 4](trabalho-4/) | Média de 4 sensores de temperatura em displays de 7 segmentos |
| [Trabalho 5](trabalho-5/) | Brilho de um LED por PWM: valor digital de 8 bits e potenciômetro |
| [Trabalho 6](trabalho-6/) | PWM de 10 kHz no Timer1 com duty cycle pelo potenciômetro |
| [Trabalho 7](trabalho-7/) | Contador UP/DOWN com dois botões, pull-up interno e debounce |
| [Trabalho 8](trabalho-8/) | Temperatura pela serial entre dois Arduinos, com média das 10 últimas |
| [Trabalho 9](trabalho-9/) | Botão no mestre e LED no escravo pelo I2C |

Cada pasta tem o código em assembly ou o sketch do Arduino (`src/`), o circuito do SimulIDE
(`simulide/`) e, quando houver, o GIF da simulação (`docs/`), mostrados no
`README.md`.
